Tentang Sistem

Analisis akademik dengan pendekatan Machine Learning.

Sistem ini menggunakan algoritma Decision Tree untuk mengolah data nilai dan kebiasaan belajar sebagai dasar prediksi kelulusan.

Metode yang Digunakan

Decision Tree Classifier

Model melakukan klasifikasi berdasarkan beberapa variabel akademik, seperti nilai semester, waktu belajar, kegagalan mata pelajaran, dan jumlah ketidakhadiran.
